## Your own video files

Resolutions run to 4K, and the aspect-ratio handling covers ultrawide monitors, which many wallpaper tools quietly ignore.

## Several monitors at once

Each display can run its own wallpaper simultaneously rather than mirroring one across all of them. On a two- or three-screen desk this is the difference between a feature you use and one you turn off after a week.

## Battery, heat and when it stops

Video on the desktop costs power, and any honest description of a live wallpaper app has to say so. Decoding a clip continuously keeps the GPU awake, which shortens runtime on a laptop and can make the fans audible on warm days.

The app handles this in two ways. Smart Pause stops playback when you are working in another application, so the video is not decoding behind a full-screen window where nobody can see it. Separately, playback pauses when the machine is running on battery or sitting idle. Both are the right defaults, but neither makes a live wallpaper free — if you work unplugged all day, expect a measurable cost.
